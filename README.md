# My Font

Turn your handwriting into a font, right in your browser. Inspired by [Ductus](https://ductus.sorenblank.com/).

**[Try it online](https://sekor.eu.org/my-font/)**

## Quick start

1. Open the app and draw letters with your mouse, finger, or drawing tablet.
2. Preview your font as you write.
3. Click **Export** to download your font.

Your letters are saved locally on your device.

## Run locally

```bash
git clone https://github.com/skorotkiewicz/my-font.git
cd my-font
bun install
bun run dev
```
